# 🤖 HH Automation Bot

**HH Automation Bot** — это мощное десктопное приложение для автоматизации поиска работы на HeadHunter (hh.ru). Приложение эмулирует действия реального пользователя, позволяя массово откликаться на вакансии, поднимать резюме в поиске и поддерживать активность аккаунта.

## 📦 Скачать готовую версию (без установки Python)

Если вы не хотите настраивать Python и работать с кодом, вы можете скачать **готовое приложение для Windows**:

1.  Перейдите во вкладку **[Releases (Релизы)](https://github.com/GNAVA4/HH_Automation_bot/releases)**.
2.  Откройте последнюю версию (помечена тегом `Latest`).
3.  Внизу в разделе **Assets** скачайте **ZIP-архив**.
4.  Распакуйте архив в любую папку на компьютере.
5.  Запустите файл `HH_Automation_bot.exe` внутри папки.

## 🆕 Что нового в 4.0
*   🧩 **Прохождение тестов работодателя** — бот отвечает на вопросы и отправляет отклик (раньше пропускал).
*   ✉️ Сопроводительное письмо прикладывается везде: в тестах и в обязательном/необязательном варианте модалки.
*   🎯 Надёжная отправка отклика — исправлено «Откликнуться не нажимается».
*   ⏹️ Кнопка «Стоп» срабатывает мгновенно даже во время выбора резюме (больше не зависает).

## 🔥 Возможности

*   **Умные авто-отклики:**
    *   Гибкая фильтрация (Регион, Зарплата, Опыт, Тип занятости и др.).
    *   Поддержка "Черных списков" слов.
    *   Работа с несколькими страницами выдачи.
    *   Интеллектуальный выбор резюме в зависимости от вакансии.
*   **🧩 Прохождение тестов работодателя (новое в 4.0):**
    *   Бот больше не пропускает вакансии с тестами — он сам отвечает на вопросы (да/нет, оценка уровня, свободные ответы) и отправляет отклик.
    *   Настраиваемые ответы по умолчанию (вкладка «Тесты»).
    *   Внешние редиректы на сайт работодателя при этом корректно пропускаются.
*   **Персонализированные письма:**
    *   Поддержка переменных `{company}`, `{vacancy}`, `{name}` в сопроводительных письмах.
*   **Активность:**
    *   Автоматическое поднятие всех резюме по кнопке.
    *   "Прогрев" аккаунта через имитацию переписки в чатах с работодателями.
*   **Мульти-аккаунт:**
    *   Поддержка неограниченного количества профилей.
    *   Одновременная работа с несколькими аккаунтами или с несколькими резюме(через создание второго профиля) (Многопоточность).
*   **Антидетект:**
    *   Скрытие WebDriver (Stealth).
    *   Эмуляция человеческого поведения (Human Mouse Move, инерционный скролл, скорость печати, время чтения вакансии и тд.).
    *   Уникальные отпечатки браузера.

## 🛠 Установка и Запуск

### Предварительные требования
*   Python **3.14.2** (или новее)
*   Google Chrome (установленный в системе)

### Шаг 1: Клонирование репозитория
```bash
git init
git clone https://github.com/GNAVA4/HH_Automation_bot.git
cd HH_Automation_bot
```
### Шаг 2: Создание виртуального окружения
```bash
python -m venv venv
# Активация для Windows:
venv\Scripts\activate
# Активация для Mac/Linux:
source venv/bin/activate
```
### Шаг 3: Установка зависимостей
```bash
pip install -r requirements.txt
```
### Шаг 4: Установка браузеров Playwright
Это обязательный шаг для работы движка автоматизации.
```bash
playwright install chromium
```
### Шаг 5: Запуск
Это обязательный шаг для работы движка автоматизации.
```bash
python main.py
```

## 🤝 Совместная разработка (Workflow)

Мы используем защиту ветки `main`. Прямые коммиты в `main` запрещены.
Вся работа ведется в отдельных ветках с последующим созданием Pull Request (PR).

### Как внести изменения (Инструкция для разработчика):

1.  **Обновите локальный репозиторий:**
    Перед началом работы убедитесь, что у вас свежая версия проекта.
    ```bash
    git checkout main
    git pull origin main
    ```

2.  **Создайте новую ветку:**
    Называйте ветку в зависимости от задачи (например: `feature/new-filter`, `fix/login-bug`, `update/design`).
    ```bash
    git checkout -b feature/название-вашей-задачи
    ```

3.  **Внесите изменения и зафиксируйте их:**
    ```bash
    git add .
    git commit -m "Описание того, что было сделано"
    ```

4.  **Отправьте ветку в удаленный репозиторий:**
    ```bash
    git push origin feature/название-вашей-задачи
    ```

5.  **Создайте Pull Request:**
    *   Перейдите на страницу репозитория на GitHub.
    *   Вы увидите желтую плашку с кнопкой **"Compare & pull request"** — нажмите её.
    *   Опишите изменения и назначьте Reviewer (владельца репозитория).
    *   Дождитесь Code Review и аппрува (одобрения).
    *   Только после одобрения ваш код будет слит в `main`.

**Важно:** Не забывайте обновлять `requirements.txt`, если вы добавили новые библиотеки:
```bash
pip freeze > requirements.txt
```

## ⚙️Использование 
*   **Настройка профиля:** 
    *   Перейдите во вкладку Настройки, Нажмите "Добавить профиль". 
    *   Откроется браузер — войдите в свой аккаунт на hh.ru(все ваши даннные сохраняются локально, в чем можно убедиться, открыв исходный код)
    *   После успешного входа браузер закроется, а профиль сохранится.
*   **Настройка профиля:** 
    *   Перейдите во вкладку Отклики. 
    *   Выберите созданный профиль. 
    *   Настройте фильтры (можно сохранить их как Пресет)
    *   Напишите назавние своего резюме(оно должно точно совпадать с тем, что есть на hh) и сопроводительное письмо (можно использовать переменные {company},{vacancy},{name}(Как в профиле))
    *   Нажмите ЗАПУСТИТЬ РАССЫЛКУ.
*   **Безопасность:** 
    *   В Настройках можно регулировать задержки и скорость действий.
    *   Рекомендуемый лимит откликов: 200 в сутки (ограничение HH).
